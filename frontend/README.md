# Фронтенд «Итоги года»

React 18 + TypeScript + Vite. Внешних UI-библиотек нет: экранов три, а вёрстка
слайдов всё равно уникальная.

## Запуск

```bash
cp .env.example .env
npm ci
npm run dev
```

Дев-сервер поднимется на `http://localhost:5173` и будет проксировать `/api` на
Go-сервис (`VITE_API_PROXY_TARGET`, по умолчанию `http://localhost:8080`).
При таком запуске задайте backend-переменную `PUBLIC_BASE_URL=http://localhost:5173`;
в Docker Compose она должна оставаться `http://localhost:3000`.

Прочие команды:

```bash
npm run build   # tsc --noEmit + сборка в dist/
npm run lint    # eslint
npm run format  # prettier
```

## Сценарий

1. **Стартовый экран** — `GET /api/v1/profiles`, выбор тестового профиля.
2. **Генерация** — `POST /api/v1/recaps` с `{ profileId, year }`, затем
   `GET /api/v1/recaps/{id}` за слайдами. Ручка идемпотентна: повторный запуск
   того же профиля возвращает уже готовые итоги, а не пересобирает их.
3. **История** — слайды листаются кнопками, прогресс сверху, на финальном экране
   плитки с числами года, старое избранное, рекомендации и кнопка «Поделиться».
4. **Публичная карточка** — `POST /api/v1/recaps/{id}/share` создаёт постоянную
   ссылку, а `/shared-recaps/{token}` загружает безопасный snapshot через
   `GET /api/v1/shared-recaps/{token}` без авторизации.

## Как устроен код

- `src/api/types.ts` — типы контракта из `backend/recap/api/recap/v1/openapi.yaml`.
  Написаны руками: фронт использует малую часть схемы.
- `src/api/client.ts` — вызовы API и разбор ошибок. Тело ошибки
  `{ code, message, requestId }`: текст для пользователя выбирается по `code`,
  серверный `message` уходит в консоль — он написан для логов.
- `src/components/Slides.tsx` — рендер одиннадцати типов слайдов. Тип приходит в
  поле `type`, числа лежат в типизированных полях, подписи — готовыми строками
  (они согласованы с числом: «4 сезона», но «5 сезонов»).

## Ограничения MVP

- `ListingRef` не содержит URL объявления. Рекомендации и старое избранное
  отображаются как информационные карточки без перехода по UUID.
- Полноценный роутер не используется: при старте отдельно распознаётся только
  публичный путь `/shared-recaps/{22-character-token}`.
